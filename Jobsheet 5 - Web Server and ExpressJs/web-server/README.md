# Jobsheet 5 – Web Server and Express.js

## Deskripsi Proyek
Jobsheet 5 ini berfokus pada praktik pembangunan **web server** menggunakan **Node.js** dengan bantuan framework **Express.js**. Pada jobsheet ini juga diterapkan sistem **templating Handlebars (hbs)** untuk menghasilkan tampilan web yang dinamis, terstruktur, dan mudah dikelola.

Aplikasi yang dikembangkan mampu menangani berbagai rute, menyajikan halaman HTML dinamis, mengirimkan data dalam format JSON, serta menampilkan halaman kesalahan (404) secara terpisah.

## Tujuan Pembelajaran
- Memahami konsep dasar web server dan cara kerjanya  
- Membedakan server statis dan server dinamis  
- Mengimplementasikan Express.js untuk pengelolaan routing  
- Menggunakan template engine Handlebars (hbs)  
- Mengelola aset statis dan tampilan web dinamis  
- Menangani error menggunakan wildcard route  

## Materi dan Tahapan Latihan
Dalam pelaksanaan jobsheet ini, beberapa tahapan yang dilakukan antara lain:

1. Mempelajari konsep web server dan mekanisme komunikasi antara browser dan server melalui protokol HTTP.  

2. Menginstal serta menggunakan framework Express.js untuk membangun web server dan mendefinisikan beberapa rute dasar menggunakan metode `app.get()`.  

3. Menerapkan response dalam bentuk HTML dan JSON untuk memahami perbedaan penyajian data statis dan dinamis.  

4. Mengelola file statis seperti HTML, CSS, JavaScript, dan gambar menggunakan modul `path` dan fungsi `express.static()`.  

5. Menggunakan Handlebars (hbs) sebagai template engine untuk menampilkan data dari backend ke halaman web secara dinamis.  

6. Membuat dan menerapkan partials seperti header dan footer guna mengurangi pengulangan kode dan mempermudah pemeliharaan tampilan.  

7. Menambahkan styling dan elemen visual seperti file CSS dan ikon cuaca untuk meningkatkan tampilan antarmuka web.  

8. Menerapkan wildcard route untuk menangani halaman yang tidak ditemukan (404) dengan tampilan yang dinamis dan informatif.  

## Teknologi yang Digunakan
- Node.js  
- Express.js  
- JavaScript  
- Handlebars (hbs)  
- HTML, CSS  

## Hasil dan Output Aplikasi
Aplikasi web server yang dibangun mampu:
- Menampilkan beberapa halaman web melalui routing Express.js  
- Menyajikan data JSON sebagai response  
- Menampilkan halaman web dinamis menggunakan template Handlebars  
- Menangani error halaman tidak ditemukan (404)  

## Kesimpulan
Melalui Jobsheet 5 ini, diperoleh pemahaman yang lebih mendalam mengenai cara kerja web server berbasis Node.js serta pemanfaatan Express.js dalam pengelolaan routing dan response.  
Selain itu, penggunaan template engine Handlebars (hbs) membantu dalam membangun tampilan web yang dinamis, modular, dan terstruktur dengan baik.  
Hasil akhir dari jobsheet ini adalah sebuah aplikasi web server sederhana yang telah menerapkan konsep routing, templating, pengelolaan aset statis, serta penanganan error secara profesional.
