# Pemrograman Berbasis Jaringan -- Node.js

Repositori ini memuat kumpulan **jobsheet praktikum Node.js** yang
dirancang untuk mempelajari konsep pemrograman berbasis jaringan, mulai
dari pengenalan Node.js hingga implementasi web server, database, dan
komunikasi real-time.\
Setiap direktori jobsheet berisi latihan mandiri beserta dokumentasi
`README.md`, sedangkan hasil praktik dan bukti pengerjaan disimpan dalam
folder tangkapan layar (screenshoot/ss).
